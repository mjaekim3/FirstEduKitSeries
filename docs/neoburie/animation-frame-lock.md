# 너부리 애니메이션 절대 프레임 기준

2026-09-22 사용자 지시: **현재 로컬 로그인 화면의 걷는 너부리를 절대 기준으로 고정한다.** 이후 모든 동작은 이 너부리의 크기를 변경하지 않고 제작한다.

## 기준 원본

- 원본: `public/neoburie-pixel-walk.png` (2172 × 724, 가로 4프레임).
- 단일 프레임 좌표계: **543 × 724 px**. 걷기 원본의 프레임 크기와 발 접지선은 계속 고정한다.
- 현재 걷기 외형 기준: `public/neoburie-wake-v4.png`의 마지막 기지개 자세. 얼굴 무늬, 부드러운 윤곽과 몸통 비율을 이 자세에 맞춰 `public/neoburie-pixel-walk-v3.png`의 열 프레임으로 제작했다. 이전 걷기 시트는 보존한다.
- 현재 로그인 표시 영역: 데스크톱 **150 × 200 CSS px**, 작은 화면 **120 × 160 CSS px**. 두 크기 모두 원본 프레임과 같은 3:4 비율이다.
- 걷는 자세에서는 발의 접지선과 몸통 피벗을 기준으로 삼는다. 팔·다리의 움직임 때문에 실루엣 경계는 변할 수 있지만 머리 크기, 몸통 길이와 높이, 골반 위치, 꼬리 뿌리 두께가 동작마다 커지거나 줄어들어서는 안 된다.

## 이후 자산 제작 규칙

1. 새 동작의 모든 프레임을 먼저 543 × 724 원본 좌표계에 배치한다. 서비스용 다른 캔버스가 필요하면 **전체 동작에 단일 변환**만 적용한다.
2. 프레임별 또는 동작별로 몸을 맞추기 위한 확대·축소를 금지한다. 자산의 빈 여백을 기준으로 자동 확대하지 않는다.
3. 동일한 접지선과 골반·어깨·머리 중심 위치를 비교한다. 점프나 눕기는 자세 때문에 중심이 이동할 수 있으나 해부학적 크기는 유지한다.
4. 좌우 전환 때 프레임 크기와 무늬의 해부학적 좌우를 보존한다. TNR된 왼쪽 귀 끝을 단순 미러링으로 반대쪽에 옮기지 않는다.
5. 새 프레임은 현재 걷기 시트 v3와 겹쳐 보고 150 × 200px 실제 표시 크기에서도 크기와 얼굴 무늬를 확인한다.

## 현재 구현 상태

로그인 컨테이너와 캔버스는 위 크기를 사용한다. 잠들기와 깨기 시트는 원본 좌표계에서 동일한 보정 배율 1.16과 고정 접지 기준 610px을 쓴다. 원본 잠자리 이미지의 기준점 차이 39px은 표시 위치에서 한 번만 보정한다. 그 밖의 care 동작에는 시트별 보정 배율(`src/app/login/neoburieCare.ts`의 `SHEET_SCALE`)이 남아 있다. 이 값만으로 모든 동작의 해부학적 크기 일관성이 검증되었다는 뜻은 아니다.

걷기 v3는 기지개 마지막 자세를 외형 참조로, 사용자가 제공한 10장의 동물 걷기 프레임을 발 순서 참조로 사용했다. 열 프레임 모두 동일한 1.22배 변환을 적용해 543 × 724px 캔버스의 접지선 610px에 배치했다. 기본 시트의 머리는 오른쪽을 보며 기존 좌우 전환을 그대로 사용한다. 기지개 끝 연결 프레임도 이 시트를 사용한다. 기존 v2 시트는 보존했다.

사냥 전 대기는 걷기 v3를 절대 해부학 기준으로 새로 그린 `public/neoburie-stalk-v14.png`의 여섯 자세를 사용한다. 배와 가슴을 바닥 가까이 낮추고 앞부분을 고정한 채, 접힌 긴 뒷다리가 번갈아 힘을 받으면서 엉덩이만 좌우로 움직인다. 프레임은 0에서 5까지 한 방향으로만 재생해 동공이 작아지지 않고 계속 확대되며, 마지막 두 자세에는 각 눈동자 바로 위에 흰 중심과 금빛 테두리의 별 반짝임이 나타난다. 가까운 커서에는 여백을 보정한 `public/neoburie-swat-v4.png`를 사용한다. 앞발을 얼굴 옆까지 천천히 높이 들고 잠깐 거리를 잰 뒤, 옆으로 크게 휘두르는 동작을 빠르게 두 번 반복한다. 먼 커서에는 위글 후 추적과 높은 점프를 사용한다. 점프는 수평 이동을 최대 45px로 줄이고 상승 높이와 체공 시간을 늘린 포물선으로 움직인다. 별도의 스크래치 그래픽은 사용하지 않는다. 모든 시트는 프레임마다 확대·축소하지 않고 543 × 724px 좌표계와 접지선 610px을 유지한다.
